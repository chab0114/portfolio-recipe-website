# Dev-licious

A multi-page recipe website built with plain HTML, CSS and JavaScript.

Originally a course project at Algonquin College, later refined for my portfolio.

## Features

- Recipe listing loaded from the DummyJSON API, with filters for meal type and sort order
- Pagination across recipe results
- Recipe detail page built dynamically with JavaScript
- Blog page with a table of contents
- Newsletter signup form (handled by Formspree)
- Shared header and footer across all pages

## Built with

- HTML5, CSS3 and JavaScript (ES modules)
- [DummyJSON](https://dummyjson.com) for recipe data
- [Formspree](https://formspree.io) for the signup form
- [Font Awesome](https://fontawesome.com) icons and Google Fonts (Dancing Script, Great Vibes, Source Sans Pro)

## Run it locally

No build step is needed. Clone the repository and open `index.html` in a browser.
